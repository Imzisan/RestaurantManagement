# 🍽️ Restaurant Management System

A **desktop application** developed using **C#** and **SQL Server** to streamline restaurant operations by managing food items, orders, billing, and sales reports.

---

## 📝 Project Overview
This project provides a comprehensive solution for restaurant management, featuring:

- **User Roles:** Admin, Staff, Manager
- **Admin:** Manage users, CRUD operations on food items, update information
- **Staff:** Take orders, generate bills, manage customer interactions
- **Manager:** View user information, generate detailed sales reports

---

## ⚙️ Key Technologies
- **Programming Language:** C# (.NET Framework)  
- **Database:** SQL Server  
- **UI Framework:** Guna UI  

---

## 🌟 Project Highlights
- Developed a **user-friendly desktop application** with an intuitive interface  
- Implemented **role-based access control** for secure feature access  
- Designed a **comprehensive billing system** for efficient customer transactions  
- Created **sales reporting tools** to assist in business analysis and decision-making
